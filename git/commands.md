Setup:
1. install git
2. Create account with Github (/bitbucket)

Create Repo:
1. Go to "+" icon at top right corner.
2. Click on create new repository (repo)
3. Give repo name
4. choose private or public
5. Get origin link (command found on 3rd last line)

Format: 
git remote add origin <link>

CONFIG:
1. git config --gloabl user.name "your_user_name"
2. git config --global user.email "your_email"


1. git init
1.1 git remote add origin <link>
1.2 git status
2. git add .
3. git commit -m "your message"
4. git push origin main
